# Identidad digital profesional: tres acciones para un estudiante de ASIR

Como orientador/a del sector tecnológico, propongo tres acciones que se refuerzan entre sí: **GitHub demuestra** lo que sabes hacer, **LinkedIn lo cuenta** y **las insignias lo certifican**.

## 1. Crear un portfolio técnico en GitHub con un homelab documentado

**Qué hacer**
- Abrir un repositorio público (por ejemplo `homelab`) aparte de los deberes de clase, con una carpeta por proyecto.
- Cada proyecto lleva un `README.md` con el objetivo, la topología o el esquema de red, los pasos y comandos clave, capturas, los problemas que surgieron y cómo se resolvieron.
- Proyectos realistas en 1º, montados con VirtualBox y Packet Tracer:
  - Servidor Ubuntu con SSH por clave, `ufw` y `fail2ban`.
  - Dominio con Windows Server: Active Directory, usuarios, grupos y GPO.
  - Red con VLAN y enrutamiento entre VLAN en Packet Tracer (subir el `.pkt`).
  - Script en Bash o PowerShell que automatice altas de usuarios o copias de seguridad.
  - Más adelante: servicios con Docker Compose (por ejemplo Nextcloud o Uptime Kuma).
- Añadir un README de perfil (repositorio con el mismo nombre que el usuario) que resuma quién eres y enlace los proyectos.

**Ritmo:** un proyecto documentado al mes.

**Cuidado:** no publicar contraseñas, claves, IP públicas ni datos de terceros, y no subir entregas evaluables copiadas tal cual.

**Por qué funciona:** un responsable técnico valora más un proyecto bien explicado que una lista de aptitudes, porque demuestra práctica real y capacidad de documentar, algo diario en administración de sistemas.

## 2. Optimizar el perfil de LinkedIn y publicar lo que aprendes

**Qué hacer**
- **Titular concreto:** «Estudiante de ASIR | Linux · Windows Server · Redes · Ciberseguridad | Buscando prácticas en empresa».
- **Foto profesional** y el mismo nombre que en GitHub, para que el perfil se encuentre y sea coherente.
- **Acerca de**, 3-4 líneas: qué estudias, qué te interesa (sistemas, redes, seguridad o nube) y qué buscas.
- **Destacados:** enlace al portfolio de GitHub y a los mejores proyectos.
- **Aptitudes y licencias:** añadir solo las reales y enlazar cada insignia o certificado conseguido (acción 3).
- **Publicar cada dos semanas** un post corto sobre un proyecto o reto: qué hiciste, qué falló y qué aprendiste, con una captura.
- **Red de contactos:** conectar con compañeros, profesorado, exalumnos del ciclo y técnicos de empresas de la zona donde podrías hacer las prácticas.
- **Limpiar la huella digital:** buscarse en Google y revisar la privacidad de las redes personales.

**Ritmo:** perfil completo en una tarde y después unos 30 minutos cada dos semanas.

**Por qué funciona:** muchos reclutadores TIC filtran en LinkedIn por palabras clave. Un perfil activo y coherente con GitHub te hace visible y genera confianza.

## 3. Conseguir insignias verificables y participar en retos

**Qué hacer:** elegir una ruta según el interés y obtener credenciales gratuitas o baratas que se puedan comprobar con un enlace público (por ejemplo, insignias de Credly).

| Área | Formación o reto | Resultado verificable |
|---|---|---|
| Redes | Cisco Networking Academy (NetAcad): *Networking Basics* o CCNA ITN, a menudo disponible desde el propio centro | Insignia digital de Cisco |
| Sistemas Linux | NDG Linux Essentials en NetAcad, como preparación de LPI Linux Essentials | Insignia o certificado LPI |
| Ciberseguridad | TryHackMe (rutas *Pre Security* y *Cyber Security 101*) y competiciones para estudiantes, como las de INCIBE | Perfil público con salas completadas y diplomas |
| Nube | Microsoft Learn (AZ-900) con Azure for Students, o AWS Skill Builder (Cloud Practitioner) | Insignias de Microsoft Learn o AWS |

- Cada insignia se enlaza en LinkedIn (Licencias y certificaciones) y en el README de GitHub.
- Los retos de TryHackMe o CTF pueden convertirse en *write-ups* para el portfolio (sin publicar soluciones de retos activos).

**Ritmo:** una insignia por trimestre; durante el curso, mejor complementar el temario que acumular cursos.

**Por qué funciona:** una credencial verificable da una prueba objetiva cuando aún no hay experiencia laboral. Además, coinciden con contenidos de 1º y 2º de ASIR, así que refuerzan el ciclo.

## Resumen del plan

| Cada trimestre | Una insignia nueva enlazada en LinkedIn y GitHub |
